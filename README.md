## 项目

**[lumen](https://github.com/lyinet/lumen)**  
一款安静、快速的 Mac Markdown 编辑器。用 Rust 和 Tauri 写成，输入即排版，磁盘上仍是普通的 `.md`。  
*A calm, fast Markdown editor for Mac.*

**[newmud](https://github.com/lyinet/newmud)**  
侠客行 AI-MUD：用 Rust 写的中文武侠 MUD 服务器，NPC 由大语言模型驱动。

**[zhouyi-xianting](https://github.com/lyinet/zhouyi-xianting)**  
周易起卦、解卦，再转成仙庭风格的 AI 生图和视频提示词。可安装的 agent skill。

**[audio-effects](https://github.com/lyinet/audio-effects)**  
给代码讲解视频生成教学旁白，支持 Qwen、Gemini 和 Seed Audio。

**[Prompt](https://github.com/lyinet/Prompt)**  
一个收集和管理 AI 提示词的网站，支持文字、图片和视频类提示词。
